# Registro Linhas de Cuidado — SCA · AVC · Sepse

Sistema local de registro de casos de Síndrome Coronariana Aguda, AVC e Sepse, com painel de registros, ficha com lógica condicional, indicadores de boas práticas e exportação em PDF e CSV. O fluxo de coleta é inspirado no do projeto Boas Práticas (PROADI-SUS), mas este não é o sistema oficial do projeto.

**Desenvolvido por Filipe Oliveira.**

## Uso
- Acesse o link do GitHub Pages ou abra o `index.html` direto no navegador (funciona sem internet).
- Os registros ficam salvos apenas no navegador do computador em que foram digitados. Nenhum dado de paciente é enviado a servidores nem a este repositório.
- Faça backup periódico em **Exportar e backup**.
